# Illustrated badge collection

Current review direction: 24 editable SVG assets matching the existing achievement IDs. The first six approved illustrations are preserved. New illustrations use one or two principal elements, dimensional metallic rims, a shared enamel palette, and no interior halo overlay.

Open index.html for the complete interactive preview, category filters, light/dark backgrounds, replay and recurring sheen. Reduced Motion disables animations.

Rebuild with `node assets/achievements/illustrated-v3/build.cjs` from the project root. Existing six scenes and material definitions are in build.cjs; the remaining artwork is in additional-scenes.cjs. manifest.json records titles, backgrounds, filenames and availability. Listener remains a future recording achievement.

This is a prototype only. No native app integration, unlock changes, or changes to the separate 90 streak checkpoints have been made.
