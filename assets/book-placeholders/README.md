# Closer placeholder book covers

The 66 SVG covers in this folder use the existing HTML-inspired library palettes and motifs. Filenames match the canonical Bible book IDs. These are the active placeholder images for book details, audio, introduction cards, search, and other book imagery.

The shelf adds paper edges and a shadow around the same visual design. Original painted art remains archived in `../book-covers` but is no longer registered for display.

To regenerate these editable assets from `constants/libraryBookArt.ts` and the book catalog, run `node scripts/export-placeholder-covers.cjs` from the project root. The script also regenerates `constants/placeholderCovers.ts`.
